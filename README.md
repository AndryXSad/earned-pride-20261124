One line, 100 characters, that gives the judge a quiet, earned moment of pride: for six years she mended other people's wedding dresses; today she sewed the last stitch on her own. The effort is felt inside the line, the pride arrives with the final words, and nothing is asserted or explained.

## Run it

```sh
python3 main.py
```

The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset), and refuses to write anything outside the 1–240 character gate.
